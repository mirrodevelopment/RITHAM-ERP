Disaster Recovery Playbook

Follow these procedures if the database crashes, corrupted records need restoration, or the office computer hardware is replaced.

1 Safe Drill / Verification Restore (No Production Risk)

Restores into a temporary isolated database ritham_erp_restore_test to confirm backup validity:

powershell -ExecutionPolicy Bypass -File "d:\ritham-erp\scripts\backup\erp-restore.ps1"

Select Option 1 (TEST restore). It will not touch production data.

2 Full Disaster Recovery (Overwrites Production Database)

In case of catastrophic data loss, stop Spring Boot and run the restore wizard:

# Step A: Close start.bat or stop Spring Boot # Step B: Run restore wizard as Administrator powershell -ExecutionPolicy Bypass -File "d:\ritham-erp\scripts\backup\erp-restore.ps1"

Select Option 2 (FULL restore) and type YES when prompted.

3 Complete Computer Replacement Checklist
  • Attach the external backup drive (E:) to the new computer.
  • Install PostgreSQL 17 from the official installer.
  • Set up credentials in %APPDATA%\postgresql\pgpass.conf.
  • Restore the latest dump file using erp-restore.ps1.
  • Register Windows Task Scheduler using setup-task-scheduler.ps1.
